# ?? Arquitectura Multi-Cliente con tpqsolutions.com.ar

## ?? Visión General

Este documento describe cómo gestionar múltiples clientes usando subdominios de `tpqsolutions.com.ar` con Cloudflare Tunnels.

---

## ?? Estrategia: Un Dominio, Múltiples Clientes

### Concepto

En lugar de requerir un dominio separado para cada cliente, todos los clientes usan subdominios de tu dominio central:

```
tpqsolutions.com.ar
??? victor.tpqsolutions.com.ar    ? Cliente Victor
??? pepe.tpqsolutions.com.ar      ? Cliente Pepe
??? abc.tpqsolutions.com.ar       ? Cliente ABC
??? xyz.tpqsolutions.com.ar       ? Cliente XYZ
??? ... (ilimitados)
```

## ?? Comparación de Estrategias

### Opción A: Subdominios de tpqsolutions.com.ar (IMPLEMENTADA) ?

| Aspecto | Descripción |
|---------|-------------|
| **URL** | `victor.tpqsolutions.com.ar` |
| **Cuenta Cloudflare** | Una sola (manuclaro@gmail.com) |
| **Gestión DNS** | Centralizada en un dominio |
| **Costo** | $0 (ilimitado) |
| **Setup** | Rápido (5 minutos/cliente) |
| **Escalabilidad** | Ilimitada |
| **Mantenimiento** | Muy simple |
| **Visibilidad marca** | TPQ Solutions |

**Ideal para:** APIs internas, servicios técnicos, backends

### Opción B: Dominio del Cliente

| Aspecto | Descripción |
|---------|-------------|
| **URL** | `sql.clientevictor.com.ar` |
| **Cuenta Cloudflare** | Múltiples o acceso compartido |
| **Gestión DNS** | Distribuida |
| **Costo** | Depende de quién pague el dominio |
| **Setup** | Más complejo (requiere coordinar) |
| **Escalabilidad** | Depende del cliente |
| **Mantenimiento** | Más complejo |
| **Visibilidad marca** | Cliente |

**Ideal para:** Servicios públicos, aplicaciones de marca blanca

### Cliente 1: Victor

#### Información
- **Nombre del negocio:** Comercio Victor
- **Ubicación:** Buenos Aires
- **SQL Server:** 192.168.1.100:1433
- **Base de datos:** Comercio

#### Cloudflare
```bash
# Tunnel
Tunnel Name: sqlbridge-victor
Tunnel ID: aaaa-bbbb-cccc-dddd-eeee

Subdominio: victor.tpqsolutions.com.ar
```

## ?? Proceso de Onboarding de Nuevo Cliente

### Checklist Rápido (15 minutos)

#### Pre-requisitos (Recopilar antes de visita)
- [ ] Nombre del cliente (para el subdominio)
- [ ] IP del SQL Server
- [ ] Nombre de la base de datos
- [ ] Credenciales de SQL Server
- [ ] Usuario de Windows en la PC

#### En la PC del Cliente

**1. Instalar dependencias (si no están)** ?? 10 min
```powershell
# .NET 8 Runtime
# NSSM
# cloudflared
```

**2. Configurar SQLBridge** ?? 3 min
```powershell
# Copiar archivos a C:\SqlBridge
# Configurar appsettings.json con connection string
# Instalar como servicio
# Iniciar servicio
```

**3. Configurar Cloudflare Tunnel** ?? 2 min
```powershell
# Autenticarse (solo primera vez por PC)
C:\cloudflared\cloudflared.exe tunnel login

# Crear tunnel
C:\cloudflared\cloudflared.exe tunnel create sqlbridge-nombrecliente

# Configurar DNS
C:\cloudflared\cloudflared.exe tunnel route dns sqlbridge-nombrecliente nombrecliente.tpqsolutions.com.ar

# Crear config.yml
# Instalar servicio
C:\cloudflared\cloudflared.exe service install

# Iniciar servicio
Start-Service cloudflared
```

**4. Verificar** ?? 1 min
```powershell
# Health check local
curl http://localhost:5000/health

# Health check público
curl https://nombrecliente.tpqsolutions.com.ar/health
```

**5. Configurar Railway** ?? 1 min
```bash
# Crear nueva instancia o actualizar variable
SQL_BRIDGE_URL=https://nombrecliente.tpqsolutions.com.ar
```

**? Total: ~15-20 minutos**

```powershell
foreach ($cliente in $clientes) {
    $url = "https://$cliente.tpqsolutions.com.ar/health"
    try {
        $response = Invoke-RestMethod -Uri $url -TimeoutSec 5
        $status = if ($response.status -eq "ok") { "?" } else { "??" }

    }
    catch {
        Write-Host "? $cliente - ERROR" -ForegroundColor Red
    }
}
```

## ?? Seguridad

### Aislamiento por Cliente

Cada cliente tiene:
- ? **Tunnel separado** - No pueden acceder a otros clientes
- ? **Credenciales únicas** - Archivo `.json` diferente por tunnel
- ? **Connection string propia** - Acceso solo a su SQL Server
- ? **Logs separados** - Por PC del cliente

### Tráfico

```
App Móvil
    ?
  HTTPS (TLS 1.3)
    ?
Cloudflare CDN
    ?
Tunnel Encriptado (Cloudflare)
    ?
SQLBridge (localhost)
    ?
SQL Server (red local)
```

- ? Todo el tráfico externo está encriptado
- ? No se expone ningún puerto al exterior
- ? Cloudflare maneja DDoS protection automáticamente

### Acceso

- ? Solo tu cuenta de Cloudflare puede gestionar tunnels
- ? Autenticación 2FA recomendada en Cloudflare
- ? Cada PC requiere credenciales del tunnel para conectarse

### Monitoreo

**Script de monitoreo diario (guardar como `monitoreo-clientes.ps1`):**

```powershell
# Archivo: monitoreo-clientes.ps1

$clientes = @(
    @{Nombre="Victor"; URL="https://victor.tpqsolutions.com.ar/health"},
    @{Nombre="Pepe"; URL="https://pepe.tpqsolutions.com.ar/health"},
    @{Nombre="ABC"; URL="https://abc.tpqsolutions.com.ar/health"}
)

$fecha = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
$logFile = "C:\Logs\monitoreo-clientes-$(Get-Date -Format 'yyyyMMdd').log"

Write-Output "========================================" | Tee-Object -Append $logFile
Write-Output "Monitoreo de Clientes - $fecha" | Tee-Object -Append $logFile
Write-Output "========================================" | Tee-Object -Append $logFile

foreach ($cliente in $clientes) {
    try {
        $response = Invoke-RestMethod -Uri $cliente.URL -TimeoutSec 10
        if ($response.status -eq "ok") {
            $mensaje = "? $($cliente.Nombre) - OK"
            Write-Host $mensaje -ForegroundColor Green
        } else {
            $mensaje = "?? $($cliente.Nombre) - Respuesta inesperada"
            Write-Host $mensaje -ForegroundColor Yellow
        }
    }
    catch {
        $mensaje = "? $($cliente.Nombre) - ERROR: $($_.Exception.Message)"
        Write-Host $mensaje -ForegroundColor Red
    }
    Write-Output $mensaje | Tee-Object -Append $logFile
}

Write-Output "" | Tee-Object -Append $logFile
```

**Ejecutar automáticamente con Task Scheduler:**
```powershell
# Crear tarea programada para ejecutar cada hora
$action = New-ScheduledTaskAction -Execute "PowerShell.exe" -Argument "-File C:\Scripts\monitoreo-clientes.ps1"
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Hours 1)
Register-ScheduledTask -TaskName "Monitoreo SQLBridge Clientes" -Action $action -Trigger $trigger
```
